# PrimoApp

Aplicativo feito em Flet para verificar se um número inteiro é primo.

## Como executar

Instale o Flet:

```bash
pip install flet
```

Depois execute:

```bash
python src/main.py
```

## Funcionamento

O usuário digita um número e clica em "Verificar".

O programa informa se o número é primo ou não.
